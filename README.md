## ⚙️ Run Locally

Want to explore or run the project on your machine?

**1. Clone the repository**

```bash
git clone https://github.com/akshaycpdev/portfolio.git
```

**2. Navigate to the project directory**

```bash
cd portfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

Check the `scripts` section in `package.json` for the correct command. For projects using Vite, this is typically:

```bash
npm run dev
```

Open the local URL shown in your terminal.
